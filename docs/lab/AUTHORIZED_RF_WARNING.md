# Authorized RF warning

This repository’s fronthaul/RU emulator and SDR lab protocols are for
**cabled, authorized, shielded, or otherwise licensed** environments only.

- Do **not** transmit RF unless you hold appropriate authorization.
- Default lab mode is **cabled IQ / loopback / recorded PCAP**.
- The software does not enable over-the-air transmission by itself; operators
  are responsible for compliance with local spectrum regulations.
